# Hercules-Battery-Adapter-for-Integration
Hercules Battery Adapter for Integration

Remix of https://www.thingiverse.com/thing:7120865

Converted the original models above into CAD workable files using F3D Prismatic conversion tool.

Modified to fit new batteries (they have a tab now that doesn't work with the original model) and removed mounting screw holes.

Completely re-worked the back plate and connection mechanism to use a PCB with spade terminals (KEYSTONE 1266) to connect to the battery terminals and screw lugs for the output (KEYSTONE 7770).

All these modifications were done to allow easy integration into other CAD projects / models.
I'm working on a DIY car diagnostic tool that needed a simple to use battery and this should be perfect for that use case.

There is a 3D photogrammetry scan of a 2.5AH battery included that I used to sanity-check the model.

Much thanks to the original creator of the model! Everything was a perfect fit except the weird tab I previously mentioned.

NOTE: The PCB has not been test-fitted into this model. I got the slowest/cheapest shipping method from JLCPCB, so modifications may be made in the near future.

The main piece should be printed vertically with no supports. I used mouse ears on the 4 corners and a smaller mouse ear on the small middle part (see [Slicer-Ears] 3mf file for example).

The back plate should be printed with the flat side touching the bed, no supports for this either.
